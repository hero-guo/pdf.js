PDF.js 黄金比例宽度功能测试

黄金比例说明：

黄金比例 ≈ 1.618，其倒数约为 0.618

功能描述： 页面宽度设置为可视宽度的黄金比例（约61.8%），用户缩放在此基础上进行

实现的功能：

  • 添加了新的缩放模式 "golden-width"，将页面宽度设置为容器宽度的黄金比例倒数（≈0.618）
  • 用户输入的数值缩放比例现在基于黄金比例基础缩放值进行计算
  • 当用户设置缩放为1.0时，页面宽度为容器宽度的61.8%
  • 当用户设置缩放为1.5时，页面宽度为容器宽度的92.7%（0.618 × 1.5）

// 设置黄金比例宽度
pdfViewer.currentScaleValue = "golden-width";

// 基于黄金比例的数值缩放
pdfViewer.currentScaleValue = 1.5; // 页面宽度 = 容器宽度 × 0.618 × 1.5

// 获取黄金比例基础缩放值（内部方法）
