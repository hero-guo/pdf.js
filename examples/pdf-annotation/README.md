# PDF 标注工具

基于 PDF.js 和 Konva.js 实现的功能完整的 PDF 标注工具，支持多种标注类型和丰富的交互功能。

## 功能特性

### 标注类型
- **INK（手绘）** - 自由绘制线条和图形
- **FreeText（文本）** - 添加文本标注
- **HIGHLIGHT（高亮）** - 高亮文本区域
- **UNDERLINE（下划线）** - 添加下划线
- **POLYGON（多边形）** - 绘制多边形区域
- **RECTANGLE（矩形）** - 绘制矩形框
- **CIRCLE（圆形）** - 绘制圆形
- **ARROW（箭头）** - 绘制指向箭头

### 核心功能
- 📄 PDF 文件加载和渲染
- 🎨 多种颜色选择
- 📏 可调节线条粗细
- 📖 多页面导航
- 🔍 缩放控制（放大/缩小/适应页面）
- 💾 标注保存和加载
- 📋 标注列表管理
- 🗑️ 清除所有标注
- ⌨️ 键盘快捷键支持

## 使用方法

### 1. 基本操作
1. 打开 `index.html` 文件
2. 点击"选择文件"按钮上传PDF文件
3. 等待PDF加载完成

### 2. 标注操作

#### 选择工具
- 点击左侧工具栏中的相应图标选择标注工具
- 选中的工具会高亮显示

#### 手绘标注（INK）
1. 选择手绘工具 ✏️
2. 在PDF上按住鼠标左键拖动绘制
3. 释放鼠标完成绘制

#### 文本标注（FreeText）
1. 选择文本工具 📝
2. 在PDF上点击要添加文本的位置
3. 在弹出的输入框中输入文本
4. 按Enter键或点击其他地方完成输入

#### 高亮标注（HIGHLIGHT）
1. 选择高亮工具 🖍️
2. 按住鼠标左键拖动选择要高亮的区域
3. 释放鼠标完成高亮

#### 下划线标注（UNDERLINE）
1. 选择下划线工具 📏
2. 按住鼠标左键拖动绘制下划线
3. 释放鼠标完成绘制

#### 多边形标注（POLYGON）
1. 选择多边形工具 🔷
2. 依次点击各个顶点位置
3. 双击完成多边形绘制

#### 矩形标注（RECTANGLE）
1. 选择矩形工具 ⬜
2. 按住鼠标左键拖动绘制矩形
3. 释放鼠标完成绘制

#### 圆形标注（CIRCLE）
1. 选择圆形工具 ⭕
2. 按住鼠标左键拖动绘制圆形
3. 释放鼠标完成绘制

#### 箭头标注（ARROW）
1. 选择箭头工具 ➡️
2. 按住鼠标左键拖动绘制箭头
3. 释放鼠标完成绘制

### 3. 页面导航
- 使用"上一页"/"下一页"按钮切换页面
- 在页码输入框中直接输入页码跳转
- 支持键盘方向键导航

### 4. 缩放控制
- 点击"放大"/"缩小"按钮调整缩放
- 点击"适应页面"自动调整到合适大小
- 显示当前缩放比例

### 5. 样式设置
- **颜色选择**: 点击颜色圆点选择标注颜色
- **线条粗细**: 拖动滑块调整线条粗细

### 6. 标注管理
- **标注列表**: 点击 📋 按钮查看所有标注
- **保存标注**: 点击"保存标注"按钮导出标注数据
- **加载标注**: 点击"加载标注"按钮导入标注数据
- **清除所有**: 点击 🗑️ 按钮清除所有标注

### 7. 键盘快捷键
- `Escape`: 取消当前操作（如多边形绘制）

## 技术架构

### 依赖库
- **PDF.js**: PDF文件解析和渲染
- **Konva.js**: 2D图形绘制和交互

### 核心组件
- `PDFAnnotationTool`: 主要的标注工具类
- 事件处理系统: 处理鼠标交互和工具切换
- 标注管理系统: 管理标注的创建、保存和加载
- 页面渲染系统: 处理PDF页面的渲染和缩放

### 数据结构
```javascript
// 标注数据结构
{
  id: timestamp,           // 唯一标识
  type: 'ink|text|...',   // 标注类型
  page: 1,                // 页码
  color: '#e74c3c',       // 颜色
  strokeWidth: 2,         // 线条粗细
  shape: KonvaShape,      // Konva图形对象
  timestamp: ISO_STRING   // 创建时间
}
```

## 注意事项

1. 需要在HTTP服务器环境下运行（不能直接打开HTML文件）
2. 大型PDF文件可能需要较长加载时间
3. 标注数据保存在本地，刷新页面前请记得保存
4. 建议使用现代浏览器以获得最佳体验

## 开发说明

### 本地开发
1. 启动本地HTTP服务器

3. 开始开发和测试
