🧪 测试步骤

  1. 文件上传测试
    • 点击"选择文件"按钮
    • 选择一个PDF文件
    • 验证PDF是否正确加载和显示
  2. 标注工具测试
    • 依次测试每个标注工具
    • 验证绘制功能是否正常
    • 检查颜色和粗细设置是否生效
  3. 页面导航测试
    • 测试上一页/下一页按钮
    • 测试页码输入框
    • 验证标注在不同页面间的保持
  4. 缩放功能测试
    • 测试放大/缩小按钮
    • 测试适应页面功能
    • 验证标注在缩放后的正确显示
  5. 保存/加载测试
    • 创建一些标注
    • 点击"保存标注"导出数据
    • 清除所有标注
    • 点击"加载标注"导入数据
    • 验证标注是否正确恢复

⚠️ 注意事项

  • 需要在HTTP服务器环境下运行，不能直接打开HTML文件
  • 推荐使用现代浏览器（Chrome 60+, Firefox 55+, Safari 12+, Edge 79+）
  • 测试时建议使用小尺寸的PDF文件（< 10MB）
  • 如果遇到CORS错误，请确保在本地服务器环境下运行

🔧 本地服务器启动

如果需要启动本地服务器，可以使用以下命令之一：

# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000

# Node.js
npx http-server

# PHP
php -S localhost:8000

然后在浏览器中访问 http://localhost:8000/examples/pdf-annotation/index.html

📊 性能建议

  • 建议PDF文件大小不超过50MB
  • 复杂标注过多时可能影响性能
  • 大量标注建议分页保存
  • 移动设备上可能需要调整触摸事件处理

🐛 常见问题

  • PDF不能加载: 检查文件格式是否正确，确保不是损坏的PDF
  • 标注不能绘制: 确保选择了正确的工具，检查是否在PDF区域内操作
  • 多边形不能完成: 需要双击来完成多边形绘制
  • 标注保存失败: 检查浏览器是否支持文件下载功能
